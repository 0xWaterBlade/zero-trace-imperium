# Security Policy

## Supported Version

| Version | Supported |
|---------|-----------|
| 1.x | Yes |

---

## Reporting a Security Issue

If you discover a security issue related to the repository itself, please open a private security report before creating a public issue.

Include:

- Description
- Affected component
- Steps to reproduce
- Expected behavior
- Actual behavior
- Suggested mitigation

---

## Scope

This repository documents an isolated educational laboratory.

The project must not be deployed in production environments.

---

## Responsible Disclosure

Please avoid publicly disclosing security issues before they have been reviewed.
