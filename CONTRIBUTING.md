# Contributing

Thank you for your interest in contributing to Zero Trace Imperium.

---

## Before Contributing

Please read the project documentation before submitting changes.

---

## Contribution Guidelines

- Keep documentation consistent.
- Follow existing Markdown formatting.
- Preserve the project structure.
- Update related documentation when necessary.
- Test scripts before submitting changes.

---

## Pull Requests

Each pull request should include:

- Description of changes.
- Reason for the update.
- Related files.
- Screenshots if applicable.

---

## Code Style

- Use meaningful file names.
- Keep scripts readable.
- Document configuration changes.
- Maintain consistent formatting.

---

## Documentation

Documentation should remain clear, accurate, and technically correct.

---

## Reporting Issues

Please include:

- Operating system
- Component
- Steps to reproduce
- Expected behavior
- Actual behavior

---

## Thank You

Contributions that improve the quality, accuracy, or educational value of the project are welcome.
