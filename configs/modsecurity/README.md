\# ModSecurity Configuration



\## Overview



This directory contains the ModSecurity Web Application Firewall configuration used to protect the Apache web server.



\---



\## Purpose



The deployed configuration enhances application-layer protection by inspecting and filtering malicious HTTP requests.



\---



\## Configuration Files



| File | Description |

|------|-------------|

| modsecurity.conf | Main ModSecurity configuration |

| crs-setup.conf | OWASP CRS setup |

| owasp-crs.md | CRS documentation |
