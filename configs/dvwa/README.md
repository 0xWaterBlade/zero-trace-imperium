\# DVWA Configuration



\## Overview



This directory contains the configuration files used by Damn Vulnerable Web Application (DVWA) during the Zero Trace Imperium laboratory.



\---



\## Purpose



The configuration supports controlled vulnerability testing inside an isolated VMware environment.
