\# UFW Firewall Configuration



\## Overview



This directory contains the Uncomplicated Firewall (UFW) configuration used by the Ubuntu Server within the Zero Trace Imperium laboratory.



\---



\## Purpose



The firewall configuration establishes the network security baseline by restricting unnecessary inbound access.



\---



\## Configuration Files



| File | Description |

|------|-------------|

| user.rules | IPv4 firewall rules |

| user6.rules | IPv6 firewall rules |

| firewall-policy.md | Firewall policy documentation |
