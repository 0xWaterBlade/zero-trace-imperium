\# Fail2Ban Configuration



\## Overview



This directory contains the Fail2Ban configuration used to protect exposed services against repeated unauthorized authentication attempts.



\---



\## Purpose



Fail2Ban was deployed to strengthen authentication security during the defensive phases of the project.
